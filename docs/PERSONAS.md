# 幼儿视角设计原则

本项目所有交互设计遵循以下原则。这些原则来自发展心理学对 2 岁儿童认知能力的普遍认识，
是 Tiny Eye 区别于所有成人向点餐助手的根本原因。

## 原则一：决策带宽只有 2

2 岁儿童的**工作记忆与抑制控制**尚在发育，面对多个选项会直接崩溃（表现为哭闹、乱指、放弃）。

→ **任何选择只给 2 项。** 不是 3 项，不是"推荐 3 个里挑"。

## 原则二：能认，不能读

2 岁儿童可以**识别**颜色、形状、熟悉物品的图片，
但**不具备阅读能力**，也无法理解"套餐""优惠""性价比"等抽象概念。

→ **全部走视觉 + 听觉通道**。文字只对家长出现。

## 原则三：拟声词是母语

"嘎嘎""咕噜""咔嚓"是孩子理解世界的高带宽通道。
孩子通过这些声音建立"这个吃起来是什么感觉"的预期。

→ **用拟声词翻译口感**，而不是用"酥脆""软糯"这类成人形容词。

## 原则四："我要"先于"我应该"

2 岁儿童没有营养学概念，但有强烈的自主意愿。
强行"为你好"式推荐会引发对抗。

→ **先满足"我要"，再由家长卡完成"应该"**。两件事分层，不混在一句话里。

## 原则五：参与感 > 正确率

对 2 岁儿童而言，"我参与了选择"本身就是巨大的正向体验，
其价值甚至高于这顿饭是否营养最优。

→ **允许孩子做出不最优但安全的选择**，只要落在家长卡的安全边界内。

## 原则六：安全边界不可让渡

噎食风险（硬、圆、大块）、过敏原、高钠是**硬约束**，
不因孩子的偏好或家长的催促而放松。

→ 触及硬约束时，**主动提示 + 给出替代**，不静默放行。

## 语言参数速查

| 参数 | 给孩子 | 给家长 |
|---|---|---|
| 单句字数 | ≤ 12 字 | 不限 |
| 抽象词 | 禁止 | 允许 |
| 数字 | 尽量不用（"两个"可以） | 允许 |
| 语气 | 软、慢、带叠词 | 平实、信息密度高 |
| 收尾 | 反问"好不好？" | 陈述句 |
