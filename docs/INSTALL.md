# 安装与配置

## 一、申请麦当劳 MCP Token

1. 打开开放平台：https://open.mcd.cn/mcp
2. 点击右上角【登录】，使用手机号完成验证
3. 登录后右上角按钮变为【控制台】，点击打开控制台弹窗
4. 点击【激活】，阅读并同意服务协议
5. Token 申请成功后**一键复制**，妥善保管

> ⚠️ 单个 Token 限 600 次请求/分钟。请勿将 Token 提交到任何公开仓库。

## 二、在 WorkBuddy 中配置麦当劳 MCP

1. 打开 WorkBuddy，左侧边栏进入【专家·技能·连接器】
2. 选中【连接器】页签
3. 点击右上角【自定义连接器】→【配置 MCP】
4. 在手动配置页面填入以下 JSON（**把 `${MCD_MCP_TOKEN}` 换成真实 Token**）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

5. 点击【保存】
6. 回到【自定义连接器】列表，将 `mcd-mcp` 设为【启用】

## 三、加载 Tiny Eye Skill

1. 将 `src/prompts/tiny-eye.md` 的内容作为 Skill 提示词加载到 WorkBuddy
2. 在对话框中开始使用，例如：

```
用 Tiny Eye 模式，帮我家 2 岁小朋友挑一餐
```

或直接触发某个模式：

```
【指一下】菜单照片已上传，小朋友戳了中间那个
【学声音】他一直在说"嘎嘎"
【今天心情】闹脾气
```

## 四、验证是否配置成功

在 WorkBuddy 对话框中输入：

```
调用 now-time-info 告诉我今天几号几点
```

若返回真实时间，说明 `mcd-mcp` 连接正常。
再试：

```
列出我附近门店当前可售的餐品
```

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 401 | Token 无效/过期/未提供 | 回到控制台重新激活并复制 Token |
| 429 | 请求超过 600 次/分钟 | 稍候重试，降低调用频率 |
| 连接器显示未连接 | JSON 格式错误或未替换占位符 | 检查 JSON 与 Token 是否已替换 |
| 查不到门店 | 定位地址不在服务范围 | 麦当劳 MCP 仅覆盖中国大陆（不含港澳台） |
