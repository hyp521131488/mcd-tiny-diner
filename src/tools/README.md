# tools · MCP 调用编排层

本目录承载 Tiny Eye 的 MCP 工具编排逻辑。

## 设计原则

1. **先描述、再确认、最后下单** —— 任何写操作前必须有人工确认闸门
2. **调用节流** —— 同一会话内对相同参数的查询做去重缓存（单 Token 限 600 次/分钟）
3. **失败可降级** —— 网络或 429 时不阻塞对话，转为「我们先看看这两个」的静态兜底
4. **零凭证** —— 不在代码中出现任何 Token 字面量，统一读取环境变量 `MCD_MCP_TOKEN`

## 建议实现顺序

| 阶段 | 内容 |
|---|---|
| P0 | 跑通 `now-time-info` → `query-meals` → `list-nutrition-foods` 三段只读链路 |
| P1 | 接入 `calculate-price`，产出「价格 + 营养」双卡 |
| P2 | 接入 `create-order`，加家长显式确认闸门 |
| P3 | 情绪适配、Why-Why 问答、历史订单记忆 |
